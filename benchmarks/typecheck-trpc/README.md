# tRPC Type-Check Benchmark

- Evaluates TypeScript type-checking performance on a project with **3,000 procedures** and **1,501 routers**, plus a typed client call for every procedure, generated by [scripts/gen.ts](./scripts/gen.ts).
- Declares every input with a vendored [Standard Schema](https://github.com/standard-schema/standard-schema) interface ([src/schema.ts](./src/schema.ts), identical in both `typecheck` projects, copied from `@standard-schema/spec` just as Zod and ArkType ship it) instead of a schema library, so schema-library types do not dilute the result, and neither library is handed its own declaration, which TypeScript would match faster.
- [src/checks.ts](./src/checks.ts) must produce type errors for a wrong input, output and handler input, so the type-check fails, instead of looking fast, if tRPC's inference ever falls back to `any`.
- Comparable to the other benchmarks in the `typecheck` group: [typecheck-orpc](../typecheck-orpc), [typecheck-trpc](../typecheck-trpc).

## How to run

```bash
pnpm bench      # this benchmark only; the numbers are printed, not saved
pnpm typecheck  # a single `tsc --singleThreaded --extendedDiagnostics` run, as in the benchmark
```

The committed results come from running the whole `typecheck` group in one session from the repository root (`pnpm bench typecheck`). See the [methodology](../../README.md#methodology).
