# tRPC Type-Check Benchmark

- Evaluates TypeScript type-checking performance on a project with **3,000 procedures** and **1,501 routers**, plus a typed client call for every procedure, generated by [scripts/gen.ts](./scripts/gen.ts).
- Uses [Standard Schema](https://github.com/standard-schema/standard-schema) instead of a specific library like Zod so the results reflect tRPC's performance without external influences.
- Comparable to the other benchmarks in the `typecheck` group: [typecheck-orpc](../typecheck-orpc), [typecheck-trpc](../typecheck-trpc).

## How to run

```bash
pnpm bench      # this benchmark only; the numbers are printed, not saved
pnpm typecheck  # a single plain `tsc --extendedDiagnostics` run
```

The committed results come from running the whole `typecheck` group in one session from the repository root (`pnpm bench typecheck`). See the [methodology](../../README.md#methodology).
