# oRPC Type-Check Benchmark

- Evaluates TypeScript type-checking performance on a project with **3,000 procedures** and **1,501 routers**, plus a typed client call for every procedure, generated by [scripts/gen.ts](./scripts/gen.ts).
- Every input uses a vendored [Standard Schema](https://github.com/standard-schema/standard-schema) interface ([src/schema.ts](./src/schema.ts), the same in both `typecheck` projects), so no schema library's types dilute the result and neither library gets its own declaration, which TypeScript would match faster.
- [src/checks.ts](./src/checks.ts) must produce type errors, so the check fails if oRPC's inference falls back to `any`.

## How to run

```bash
pnpm bench      # this benchmark only (printed, not saved)
pnpm typecheck  # one `tsc --singleThreaded --extendedDiagnostics` run
```

Committed results come from `pnpm bench typecheck` at the repository root, which measures the whole group in one session; see the [methodology](../../README.md#methodology).
