# tRPC WebSocket Runtime Benchmark

Run the benchmark with:

```bash
pnpm bench
```

## Overview

This benchmark evaluates the performance of tRPC's RPC runtime over **WebSocket** on a project with **6 procedures** and **3 routers**.

We use [Standard Schema](https://github.com/standard-schema/standard-schema) instead of a specific library like Zod to ensure the results reflect tRPC's performance without external influences.

Since [autocannon](https://github.com/mcollina/autocannon) only supports HTTP, the load is generated by a custom client ([scripts/client.ts](./scripts/client.ts)): 10 concurrent connections, each running one request at a time through the real tRPC WebSocket client for 20 seconds — mirroring autocannon's defaults in the HTTP benchmarks.

Benchmarks in the `ws` group are comparable to each other: [ws-orpc](../ws-orpc), [ws-trpc](../ws-trpc).

Each run profiles the server with [Clinic.js Doctor](https://clinicjs.org/doctor/) and overwrites the report at [public/clinic-doctor.html](./public/clinic-doctor.html).
